# Sandeep Kumar Chaurasiya — Portfolio

🌐 **Live site:** https://sandeepkumarchaurasiya.github.io

My personal portfolio website — a premium single-page site with a 3D animated hero, photo gallery, experience timeline, projects, publications, certificates, and one-click résumé download.

## ✨ Highlights

- 3D particle hero with an interactive portrait medallion (draggable, gold ring)
- Typing role titles, animated counters, scroll-reveal sections
- Gallery, Skills, Experience, Projects, Publications, Achievements, Education, Certificates, Résumé and Contact sections
- One-click résumé download (PDF bundled as a data URI — works fully offline)

## 🛠️ Built with

HTML · CSS · JavaScript · Three.js — no frameworks, no build step. Deployed with GitHub Pages.

## 📁 Structure

- `index.html` — the entire site
- `assets/photos/` — profile and gallery photos (embedded as JS data URIs)
- `assets/certs/` — certificate images (embedded as JS data URIs)
- `assets/resume/` — downloadable résumé PDF (embedded as a JS data URI)
